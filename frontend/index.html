Google Cloud Project & Service Account Setup Guide

Follow these 4 simple steps to connect your personal or organization Google Drive:

Quick 3-Minute Setup
1
Create or Select a Google Cloud Project
Navigate to the Google Cloud Console. Click New Project, name it warranty-management, and click Create.
↗ Open Google Cloud Console
2
Enable Google Drive API
In your Google Cloud project, open the API Library and click the blue Enable button for the Google Drive API.
↗ Enable Google Drive API in Cloud Console
3
Create Service Account & Generate JSON Key
Go to IAM & Admin > Service Accounts > Create Service Account. Name it drive-sa, grant role Editor, then click into the service account > Keys > Add Key > Create new key > JSON. A .json file will download to your computer.
↗ Create Service Account
4
